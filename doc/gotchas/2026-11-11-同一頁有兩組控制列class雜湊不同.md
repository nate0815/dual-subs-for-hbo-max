# HBO 播放頁同時有兩組 `control_footer`，class 雜湊不同

**現象**
- 在播放頁列出控制列按鈕，`div[data-testid="control_footer"]` 出現**兩組**：一組 class 雜湊是 `sc-aeee95d2`、有「音訊和翻譯字幕設定」按鈕；另一組是 `sc-11d13d64`、**沒有**那顆按鈕（只有音量、全螢幕等）。
- class 名稱長得像 `ControlsFooterBottomRight-Fuse-Web-Play__sc-aeee95d2-14.iMHCfS`。

**原因**
- class 是 styled-components 產生的雜湊，同一個元件在不同版面（推測是不同狀態或版型的控制列）會有不同雜湊，HBO 每次改版也會變。
- 為什麼同時存在兩組**未證實**（可能一組是隱藏中的另一種版型）。

**解法**
- **不用 class 當選擇器**，只用 `data-testid`。
- 不要直接抓 `control_footer`（會抓到錯的那組）；改從 `button[data-testid="player-ux-track-selector-button"]` 找起，取它的 `parentElement` 當右下群組，並確認它看得見（`getBoundingClientRect().width > 0`）。
