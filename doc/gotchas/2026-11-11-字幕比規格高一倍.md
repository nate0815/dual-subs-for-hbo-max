# 字幕位置比規格高很多（底部留白約一倍）

**現象**
- DESIGN 規定字幕底部留白是「影片高度的 9%」，實機上字幕卻離下緣約影片高度的 18%，看起來偏上。

**原因**
- `overlay.js` 寫的是 `paddingBottom: '9%'`。**CSS 的 padding 百分比（含上下方向）一律相對於包含區塊的寬度**，不是高度。16:9 寬螢幕上，寬度約是高度的兩倍，於是留白變成高度的 18% 左右。
- 單元測試不涵蓋 DOM，只有實機看得出來。

**解法**
- `BOTTOM_PAD` 改成比例數字（0.09），在 `place()` 裡用 `video.getBoundingClientRect().height` 換算成 px 再設定。
- 之後任何「影片高度的 X%」的版面數值都要這樣換算，不要直接寫 CSS 百分比。
