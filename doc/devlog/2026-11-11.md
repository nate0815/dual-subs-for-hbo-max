**追加：偵察 HBO 控制列 DOM**（Adventure Time 第 1 季第 19 集，暫停狀態）
- Claude in Chrome 在這個 Claude Code 工作階段沒有連上（工具不存在），改由 Nate 在 DevTools 主控台跑一段只列按鈕結構的腳本、貼回結果。不含字幕內容。
- 右下群組：`div[data-testid="control_footer"]` > `ControlsFooterBottomRight` > 依序為 `volume-container`（音量）、`button[data-testid="player-ux-track-selector-button"]`（aria「音訊和翻譯字幕設定」）、`button[data-testid="player-ux-fullscreen-button"]`。外層是 `AutohiderContainer`（會自動隱藏），由 React 管理。
- 嵌入策略：從 track-selector 按鈕找 `parentElement`，按鈕插在它旁邊；每次 tick 檢查按鈕還在不在，被 React 重繪掉就插回去。
- [同一頁有兩組控制列class雜湊不同](../gotchas/2026-11-11-同一頁有兩組控制列class雜湊不同.md) —— 只能用 `data-testid`。
- 附帶發現：
  - `div#overlay-root[data-testid="overlay-root"]`（aria「video player」）是播放器根節點 —— H3 若全螢幕出問題，疊加層可改掛這裡。
  - 原生字幕選單的軌按鈕是 `button[data-testid="player-ux-text-track-button"]`，含 aria「關閉」那顆 —— 自動關閉原生字幕（待決 #3）技術上有路，但仍依賴 DOM。
  - 原生選單的軌名稱是「關閉／中文 (繁體)／英文 CC」；本集音軌有英文原始、國語、粵語、印尼文、泰文、馬來文。我們的選單可用 `Intl.DisplayNames` 從語言代碼產生中文名稱，`caption` 角色加「CC」。
