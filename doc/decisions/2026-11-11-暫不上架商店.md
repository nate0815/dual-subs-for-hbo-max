# 暫不上架 Chrome Web Store，要分享先走不公開

**選了什麼**
- 維持自用「載入未封裝項目」。要給別人用時，先用商店的「不公開」或「測試人員」可見度；不直接公開上架。

**沒選什麼、為什麼不選**
- 直接公開上架。技術上可行（一次性註冊費約 US$5，需隱私權政策與權限說明，送審），但有四項風險尚未評估：
  1. **版權／服務條款**：自用時字幕只在自己瀏覽器的記憶體處理；公開上架等於公開散布讀取 HBO Max 字幕的工具，服務條款可能不允許，內容方可能提出下架。未評估，也不是法律意見。
  2. **商標與命名**：名稱、圖示、說明、截圖不能暗示與 HBO 有關，不能放劇的畫面。
  3. **維護負擔**：HBO 改清單檔格式，所有使用者同時壞掉，修復責任在自己。目前只在一集上驗證過。
  4. **審核**：在 `hbomax.com` 主世界注入腳本，需在說明裡講清楚只讀字幕、不蒐集資料。

**如果錯了會怎樣**
- 若其實沒人檢舉、服務條款也沒問題，只是多等了一段時間，損失很小。反過來，太早公開而被下架，會影響整個開發者帳號。
- 重新考慮的條件：H3、H4 驗完，服務條款評估過，且確定有人要用。屆時開新決策推翻本則。
