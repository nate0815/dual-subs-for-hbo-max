# 不經 Chrome Web Store 分享

**選了什麼**
- 正式形式維持「載入未封裝項目」。未來會想分享給別人，但**不經商店** —— 包括「不公開」與「測試人員」可見度也不走。
- repo 目前不公開。具體的分享管道（私下給 zip、私人 repo 邀請等）列入 DESIGN「待決事項」。

**沒選什麼、為什麼不選**
- 先前的決策〈暫不上架商店〉寫的是「要分享先走不公開或測試人員」—— 那兩種仍是商店，要開發者帳號、隱私權政策、送審，而且被檢舉時影響的是整個開發者帳號。Nate 明確表示不上商店。
- 版權、服務條款、商標、維護負擔四項風險的分析仍然成立（見舊那則），只是應對方式從「商店的哪種可見度」變成「不進商店」。

**如果錯了會怎樣**
- 若日後想讓不認識的人也能裝，私下分享會不夠用，屆時再開新決策評估商店。
- 私下分享仍然是散布，分享前要先評估服務條款（DESIGN「待決事項」）。
